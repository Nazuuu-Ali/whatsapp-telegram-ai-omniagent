# 🤖 24/7 Multi-Channel AI OmniAgent (WhatsApp & Telegram)

Production-ready 24/7 AI OmniAgent built with n8n, Google Gemini 1.5 Flash, and Supabase. Automates real-time sales & support across WhatsApp & Telegram with persistent memory.

An enterprise-grade, autonomous **AI OmniAgent** built using **n8n**, **Google Gemini**, **Supabase PostgreSQL**, and deployed on **Railway Cloud**. It automates customer support, lead qualification, and real-time contextual conversations across both WhatsApp and Telegram.

---

## ⚡ Architecture & Tech Stack

- **Workflow Orchestration:** n8n (Self-hosted / Cloud)
- **AI / LLM Engine:** Google Gemini  (Structured Prompts & Guardrails)
- **Database & Memory:** Supabase (PostgreSQL for session history & lead deduplication)
- **Deployment & Hosting:** Railway Cloud (Sub-2s response latency)
- **Integrations:** Meta Cloud API (WhatsApp Business) & Telegram Bot API

---

## 🛠️ Key Features

- **Multi-Channel Orchestration:** Unified n8n workflow routing both WhatsApp and Telegram webhooks smoothly.
- **Persistent Contextual Memory:** Tracks customer conversation state and history via Supabase tables.
- **Automated Lead Capture:** Validates incoming leads, cleans contact data, and stores qualified prospects.
- **Multilingual Support:** Dynamic language adaptation (English, Roman Urdu, etc.).
